# 筑梦启动器 0.0.1-preview.2

第二个 Windows x64 预览版，重点完善安装体验、游戏实例维护与启动过程反馈。

## 本版更新

- 重绘安装向导的页面配色、文字层级和浏览按钮，并统一卸载页的筑梦视觉风格。
- 完善独立游戏实例管理入口，可在启动器内查看和维护 Mod、存档、截图及实例文件。
- Mod 支持禁用与恢复：禁用时改为 `.zhumeng` 后缀保留原文件，启用时恢复原扩展名。
- 改善 Java 自动发现、版本兼容选择与缺失运行时下载流程，并补充问题诊断和启动日志入口。
- 调整游戏启动等待动画的结束判定，检测到游戏窗口或 PCL 图形初始化信号后退出遮罩。

## 已知限制

这是尚未代码签名的预览版，Windows 可能提示未知发布者。微软正版登录仍依赖用户自行准备并配置的受支持 PCL 程序；CurseForge 部分搜索需要用户自己的 API key。自动化测试无法替代用户环境中的完整微软授权和真实游戏验证。筑梦启动器仍在持续补齐与 PCL 的交互和功能差异。

如果遇到问题，请在 [Issues](https://github.com/beizilaoshi/Buildingdreams/issues) 提交复现步骤、系统版本及脱敏日志。不要上传账号库、令牌或私人路径。
