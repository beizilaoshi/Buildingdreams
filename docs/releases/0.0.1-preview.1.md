# 筑梦启动器 0.0.1 预览版

首次公开预览，面向 Windows x64。

- 月湖绘本风景与玻璃界面，2.5D 动态背景、开场动画和 49 项外观设置。
- 4 个外观预设，最多 24 个个人方案，支持方案导入与导出。
- 原版及 Fabric / Quilt / Forge / NeoForge 安装，游戏资源根目录与实例隔离。
- Mod 与整合包中文查找、资源安装、Java 自动管理，以及任务和通知。
- 本地身份与外部 PCL 微软授权桥接；启动时提供贪吃蛇等待动画。
- GitHub 版本检查，支持预览 / 稳定通道与手动检查，由用户选择下载更新。

## 使用前请留意

这是未签名的预览版，Windows 可能提示未知发布者。免安装版默认仍将数据保存在 Windows 应用数据目录。更新检查不会自动替换或执行程序。

微软登录需要 .NET Framework 4.8 与用户另行准备的受支持 PCL 可执行文件，并在设置中配置路径。真实微软交互授权、游戏所有权和完整游戏运行需要用户在自己的环境中验证；自动化检查不能代替这些步骤。本地身份不能替代正版授权。

CurseForge 部分能力需要用户自己的 API key；受限文件需按界面指引手动补齐。部分历史 Java 需手动提供。2.5D 背景不是 Cubism 模型，功能尚未与 PCL 全面对齐。

问题与建议请提交到 [Issues](https://github.com/beizilaoshi/Buildingdreams/issues)，附复现步骤与脱敏日志，勿上传账号库或令牌。许可和来源见仓库第三方说明。
