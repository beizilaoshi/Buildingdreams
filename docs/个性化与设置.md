# 个性化与设置

“个性化”是可搜索的卡片工作台，所有分组直接展开。可以先选“月湖星语”“云海晨光”“极简深色”或“清透浅色”，再逐项调整。月映湖仍为默认背景，另有同风格的樱庭星夜、云海晨光，以及方块系列等可选背景。

## 可调整的内容

- 背景：内置图片、本地图片、渐变或纯色，图片填充、亮度、模糊、饱和度、水平和垂直位置、缩放、暗色遮罩与暗角。
- 动态背景：静态、自动或交互模式，可调强度、速度，选择自动/花瓣/星光/无粒子，以及低/均衡/高性能档位。交互模式加入鼠标视差；自动模式只播放环境动效。减少动态效果、切到后台或使用纯色/渐变背景时会停用渲染；动态不可用时保留静态背景。
- 材质：深浅主题、磨砂/清透/实色卡片、强调色、不透明度、模糊、折射、边框、阴影与圆角。
- 排版：首页标题和副标题、字号与对齐、引言显示、界面字体及文字缩放、导航文字与宽度、内容宽度、卡片间距与密度、游戏库显示方式。
- 动效：页面切换、开场主题及速度、界面动画速度、粒子、鼠标光影、减少动态效果及通知位置。系统的减少动态效果偏好优先。

修改会即时预览并自动保存。每个分组都有独立重置；“恢复全部默认外观”只重置外观，不会修改账号、Java、内存、安装目录或游戏启动配置。

如果保存失败，页面会显示未保存状态并提供重试；换页后仍保留待保存的修改。未保存的外观不会被悄悄导出为旧方案，请先重试保存。

## 我的方案

可以把当前外观保存成自己的方案，最多24个，随后应用、改名或删除。导出 JSON 只包含外观，不包含账号、令牌、Java 参数、游戏目录或个人方案列表。

导入会先校验并显示待应用内容，确认应用后才改变外观。本地背景照片不随 JSON 打包，换设备后需要重新选择图片。

## 设置页

设置页按分类展示卡片，支持搜索。搜索不会销毁正在填写的表单，清除搜索后可继续编辑。

常用设置包含启动时打开的页面、启动最大化、任务完成和失败的自动通知开关。通知开关不删除任务记录，也不隐藏手动操作的错误。

运行环境、账号、内容来源、安装目录和游戏启动配置继续保留。Java/内存及启动选项的“当前实例”和“全局默认”作用范围以对应卡片说明为准。设置页提供个性化入口，外观调整统一在个性化工作台进行。
