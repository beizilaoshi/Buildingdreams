# 安装与目录

在“下载”中选好 Minecraft 和加载器版本后，可以修改游戏名称及安装位置。名称默认随版本和加载器生成；手动修改后会保留，点击“恢复自动名称”可重新跟随版本。

安装位置留空时使用当前默认值，页面会显示实际路径。输入新目录或选择文件夹后，仅影响本次安装；点击“设为默认安装位置”才会保存为以后使用的默认值。

新安装使用以下布局：

```text
选择的安装位置/
  游戏名称/
    game/
      saves/
      mods/
      config/
      resourcepacks/
      shaderpacks/
```

每个实例的游戏目录独立。旧实例继续使用原有目录，不会自动搬迁。

提交安装后可以在任务中查看进度、取消或重试。失败后重试会校验并复用已完成的缓存文件。相同安装正在进行时，再次提交会关联已有任务；目标目录已有文件时不会覆盖。

如果中断发生在文件准备完成、游戏库登记之前，页面可能提供恢复入口。只有主动点击导入才会加入游戏库。无法识别的旧目录需要通过游戏库手动导入，不会自动删除或接管。
