Java runtime selection rules are selectively referenced from the user-authorized PCL 2.12.7.3 ModLaunch.vb (McLaunchJava) and ModJava.vb (JavaSelect/GetJavaDownloadLoader), independently implemented in TypeScript. The original PCL LICENCE is preserved in notices/PCL-LICENCE. See docs/pcl-source-references.md for exact source paths and adapted behavior.

Portable JVM downloads are fetched separately from official Eclipse Adoptium API / adoptium Temurin GitHub releases, verified with SHA-256 and exact size, and retain all upstream legal/license files. No Java payload is embedded in the launcher executable. Eclipse Temurin/OpenJDK and Java trademarks and licenses belong to their respective owners.
